# EVAL-DEV-1 — Prueba de desempeño (60 min)

Construir, desde cero y apoyándote en Claude Code + Agent SDK, un **agente autorreparable** (self-healing):
un agente autónomo que mantiene sano un proyecto de software sin intervención humana. Cuando el build o
los tests se rompen, diagnostica, aplica una corrección, verifica y repite hasta recuperar el verde o
agotar un presupuesto que tú defines.

La prueba está documentada en cuatro archivos. Léelos en orden 1 → 3; el anexo se consulta cuando lo
necesites.
